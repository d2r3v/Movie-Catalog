# Movie Catalog App

The Movie Catalog App is a web-based platform designed to enhance your movie-going experience. This application provides a comprehensive catalog of the latest movies currently playing in theaters, complete with engaging trailers.

##  Key Features

- **Real-Time Movie Updates**: Stay up-to-date with the freshest releases in the cinema world. Our catalog is updated in real time to ensure you never miss out on the latest blockbusters.
- **Interactive Review System**: Engage in lively discussions about your favorite films. Our platform allows users to post their own reviews and read insights from other movie enthusiasts.
- **Ticket Booking Redirect**: Simplify your movie-going experience with our integrated ticket booking feature. With just a click, users can be redirected to a trusted ticket booking website.

The goal is to create a dynamic and interactive community for movie lovers.

## Frameworks Used

- **SpringBoot** was used for the backend and APIs.
- **MongoDB** was used as the database to stores and fetch data from.
- **React JS** was used to build the front end of the Application
